# Rendered copy (generated)

Generated by `.githooks/pre-commit` from the committed tree with the example values in
`vars.template.yml`, so the Jinja in `src/`, `docs/` and `tools/` can be read as the
files the nodes get. Don't edit it: edit the templates and commit, and the hook
regenerates it. Files still ending in `.j2` get their second render pass on the node
at service start (see docs/development.md).
