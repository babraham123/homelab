# AGENTS.md

## Purpose

Infrastructure-as-code for a self-hosted homelab: configuration files, Jinja2 templates, and
bootstrap scripts for running a zero-trust private cloud on Proxmox VMs with Podman containers.

`rendered/` is generated by `.githooks/pre-commit` from the templates and `vars.template.yml`: read
it to see rendered output, but edit only the templates.

## Placeholders and real values

- Tracked files hold placeholders only: `vars.template.yml`, `rendered/` (rendered from it) and every
  example in `src/`, `docs/` and `tests/`. An address like `192.168.4.1` there is an example.
- Real values live only in the gitignored `vars.yml` of the main checkout,
  `/Users/bereket/Personal/homelab/vars.yml` (worktrees don't have it). Read it when reasoning about
  the real network and hosts, and keep its values out of tracked files, docs, commit messages and
  issues.
- When a value isn't in `vars.yml`, ask for it.
- Ask whether a service is deployed on a host before relying on it; the repo shows what's written,
  not what's applied.

## Worktrees

New worktrees branch from the main checkout's `HEAD`, local `main` (`worktree.baseRef` in
`.claude/settings.json`). Before starting work in an existing worktree, rebase it on local `main`,
not `origin/main`.
